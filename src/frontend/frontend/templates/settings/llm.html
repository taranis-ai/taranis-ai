OrcaRouter Cyber Inference

A named provider for authorized, scoped security inference from verified security teams. Use an OrcaRouter API key (sk-orca-…); save, replace, or remove it below. OrcaRouter Cyber Inference supports Responses and Chat Completions for Chat, clustering, summarization, NER, and sentiment. Topic classification keeps using its existing Decisions endpoint.

Provider overview | Cyber model catalogue | Manage API keys

Recommended: OrcaCyber Ultra (orca/orcacyber-ultra-1.0) and OrcaCyber Zero (orca/orcacyber-zero-1.5) for verified security teams; orcarouter/auto is the default and orcarouter/fusion is the general fallback. Cyber models are available through Chat Completions; Responses uses response-capable models such as orcarouter/auto.
